# Lung Cancer Prediction

This project explores the use of **Radiomics and Machine Learning** techniques for lung cancer prediction, using features extracted from Computed Tomography (CT) medical images.

The main goal is to investigate how quantitative imaging features can support the analysis and classification of lung nodules through computational methods.

## Project Overview

The project focuses on medical image analysis, combining radiomics feature extraction with machine learning approaches to investigate patterns associated with lung nodules.

The work involves exploring medical imaging datasets, processing CT scans and investigating how extracted features can be used for predictive modeling.

## Methodology

**Medical Imaging Data:** Exploration of lung CT imaging datasets, including LIDC-IDRI and LNDb, for lung nodule analysis.

**Image Processing:** Preparation and processing of CT images and associated nodule annotations.

**Radiomics Feature Extraction:** Extraction of quantitative features from medical images to characterize lung nodules.

**Feature Analysis:** Analysis of extracted features to identify relevant information for predictive modeling.

**Machine Learning:** Application of machine learning techniques for lung nodule classification and lung cancer prediction.

## Datasets

- **LIDC-IDRI:** A publicly available lung imaging dataset containing CT scans and nodule annotations, including segmentation masks.
- **LNDb:** A lung nodule dataset containing CT imaging data and nodule annotations, including centroid-based localization.

These datasets provide different annotation formats and were used to explore medical image analysis and radiomics workflows.
